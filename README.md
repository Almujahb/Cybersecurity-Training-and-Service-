## 🎓 Cybersecurity Training

Our training is designed for learners progressing from beginner to advanced levels.

### Training Levels

**Basic — 3 Months**
Foundation in cybersecurity concepts, Linux, networking, security tools, and practical security exercises.

**Intermediate — 6 Months**
Deeper practical cybersecurity training, vulnerability assessment, web security, network security, and security monitoring.

**Professional — 1 Year**
Advanced practical cybersecurity learning, security testing, defensive security, monitoring, lab exercises, and professional development.

Training is available through **online and physical classes**, with practical exercises and learning materials.
